# Attendr

Attendr is a self-hosted staff presence and in/out board application for Windows.

See at a glance who is:

- In the office
- Working remotely
- Out of office
- On leave
- Unavailable

## Free forever

Attendr is free forever for up to **30 active users**.

- No trial period
- No credit card required
- No subscription
- Full platform access

Need more than 30 users?

A **A$100 one-off licence** unlocks unlimited users for a single Attendr installation, with no expiry.

## Features

- Real-time staff presence
- Custom statuses
- Kiosk mode
- User profiles
- Departments and locations
- IP-based location detection
- Active Directory integration
- Azure AD integration
- Self-hosted deployment
- Runs entirely on your own infrastructure

## Getting started

1. Download `Attendr-v1.0.1-Windows.zip`
2. Extract the ZIP to your preferred folder
3. Run `start.bat`
4. Open `http://localhost:3000`
5. Complete the setup wizard

## Requirements

- Windows 10 or Windows 11
- Windows Server 2016 or newer

Attendr includes its required runtime components.
